# Catspot

A real-world cat spotting and collection game — the competent version of the CatchCat concept.

> **Status:** Research & planning phase. No live build yet.  
> **Why:** CatchCat proved "Pokémon GO for cats" is a viral idea, but shipped a 3.0★ execution. We’re building the version that actually works.

## 🎯 Core Idea in One Sentence

Point your phone at a real cat, verify the sighting, and turn it into a collectible keepsake card with rarity, stats, and personality — then build an album, share with friends, and (later) battle with your catches.
